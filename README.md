

**Установка**

```
npm i
```

**Запуск**

```
npm run start
```

**Сборка**

```
npm run build
```

**Предпросмотр**

```
npm run preview
```

**Авторские права**

Все используемые для работы над проектом материалы предоставляются партнёрами Чемпионата. При публикации итогового кода проекта в рамках портфолио участники обязаны указывать авторские права партнёров и организаторов Чемпионата:

- **Шрифт:** TypeType
- **Дизайн, макет:** Only
- **Организатор:** [htmlacademy.ru](https://htmlacademy.ru/)
